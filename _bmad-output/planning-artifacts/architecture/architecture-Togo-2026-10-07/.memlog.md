- (direction) Fast path chosen by user; spine is the sole deliverable (no secondary decks or reports required).
- (constraint) Platform: Native Android app (Kotlin), reference test device Android 16, minimum SDK API 24 (with desugaring).
- (constraint) Local-first 100%: SQLite/Room local persistence; no mandatory network dependencies for core list, catalog, history, or learned rules.
- (decision) Paradigm: Clean Architecture with Unidirectional Data Flow (UDF) and MVI pattern in Jetpack Compose UI. Strict separation between presentation, pure Kotlin domain, and data layer.
- (decision) AD-1: Pure Kotlin Domain Layer for Core Logic [ADOPTED] - Binds: parser, normalizer, duplicate-detector, taxonomy models. Prevents: coupling business logic to Android framework. Rule: domain package must have zero android.* imports.
- (decision) AD-2: Single-Writer Local Persistence via Room & Kotlin Flow [ADOPTED] - Binds: active shopping items, history, learned rules, custom taxonomy. Prevents: state desynchronization and inconsistent reads. Rule: Room SQLite is the Single Source of Truth; UI observes immutable StateFlows emitted from Repositories.
- (decision) AD-3: Pre-populated Read-Only Catalog Seed with User-Defined Overlay [ADOPTED] - Binds: 1400+ canonical products, synonyms, Level 1-3 taxonomy. Prevents: slow cold starts and corruption of baseline catalog on user edits. Rule: baseline curated catalog is bundled as immutable asset/pre-packaged SQLite; user additions are tracked with custom flags/tables.
- (decision) AD-4: Decoupled Speech Capture Gateway via Android RecognizerIntent [ADOPTED] - Binds: voice input sheet, speech transcription. Prevents: tight coupling to external AI or speech SDKs, and failure when offline. Rule: speech capture is isolated behind VoiceRecognitionGateway. Fallback to manual entry is immediate and non-destructive.
- (decision) AD-5: Deterministic Pipeline for Voice & Text Input (Parse -> Resolve -> Deduplicate -> Confirm) [ADOPTED] - Binds: voice sheet, manual add/edit, duplicate dialog. Prevents: silent writes, unverified unit conversions, unconfirmed overwrites. Rule: Every item entry passes through tokenize/extract, catalog match, duplicate check, user confirmation.
- (decision) AD-6: Unidirectional Data Flow (UDF) & Screen State in Presentation [ADOPTED] - Binds: all Compose screens, dialogs, sheets. Prevents: multiple mutable state holders and recomposition loops. Rule: Each screen is driven by single immutable UiState data class exposed via StateFlow from a ViewModel, handling sealed UiEvents.
- (decision) AD-7: Android Share Intent for Plain-Text Shopping List Export [ADOPTED] - Binds: sharing feature. Prevents: dependency on external cloud sync or leaking private history. Rule: List export formats active items into categorized plain text via Android ACTION_SEND intent without private metadata.
